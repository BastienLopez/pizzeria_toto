# Codebase Memory : Le Verone

Ce guide concerne le dépôt pizzeria_toto et uniquement ce dépôt.

## État vérifié
Le projet n’apparaît pas dans les projets indexés au 28 octobre 2026. L’architecture de cette petite vitrine reste accessible par ses sources connues : data/, src/, scripts/ et tests/.

## Règle de travail
Utiliser le graphe lorsque ce projet est déjà indexé. Sinon annoncer le fallback et lire les fichiers utiles. Ne pas indexer, réindexer, supprimer de cache, arrêter un service ou changer une configuration globale sans demande explicite.

## Si une indexation est demandée
Vérifier la documentation et les options de la version installée, cibler le chemin exact de ce dépôt et exclure les fichiers générés / caches. Ne pas reprendre de commandes ou d’identifiants d’un autre dépôt.

Les instructions de travail sont dans ../AGENTS.md et les décisions durables dans ../PROJECT_MEMORY.md.
